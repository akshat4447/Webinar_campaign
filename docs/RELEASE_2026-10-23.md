## Cleanup and rollback

A protected pre-fix source/config archive, Git bundle, unrelated-export manifest and pre-deploy hosted database dump are stored outside this repository in `../webinar-release-backups/before-fixes-20261023-214657/`. Secret environment exports and database dumps have restrictive file permissions and are excluded from Git. Thirty-three unrelated root exports were moved to that backup rather than destroyed. Local `.env` files, application source, migrations, the active development build and existing user work were preserved. A scan of 574 publishable files found no matches for nine configured secret values; this complements, rather than replaces, review for unknown secrets.

For rollback, retain the database snapshot and original encryption/signing keys. Review migration reversibility before serving old code against a migrated schema; a Git rollback alone does not reverse database changes. The restored disposable copy demonstrated data recoverability, not a timed cloud failover objective.
