Total: **6,461 authenticated page requests, zero observed failures**. Post-stress health requests all return 200. Peak sampled server RSS is **514 MiB**, exceeding the free web instance's 512 MB allocation before allowing for runtime overhead. Throughput plateaus around 55–66 requests/second during the ramp and latency degrades sharply at 100–200 concurrent requests. The test does not demonstrate a production latency objective at those loads.

Registration concurrency: 100 requests at concurrency 25 against 50 seats result in exactly 50 registrations and 50 capacity rejections. Fifteen duplicate requests add no contacts and leak no private attendee access. A ten-attempt varying-IP probe is below the new account-wide limit; the separate final login suite tests exhaustion of that global budget.
